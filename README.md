# clients.fresthomes.com

Frest Homes client area, English edition (after the first meeting). AES-GCM encrypted pages, registered e-mail + passcode (PBKDF2-SHA256 300k, per-person wrapped keys). Per-client project pages under p/<slug>/ use their own content key wrapped only for that client and the Frest team. Users are shared with clients.frest.lv (`clients/data/users.json`) — one credential opens whichever domain a client's project belongs to. A project is routed by its `market` field in `clients/data/projects.json`: `LV` builds into clients.frest.lv, anything else into clients.fresthomes.com. Add/revoke: edit those two files, rebuild, upload. Generator in Drive `WEB/gates/`.
